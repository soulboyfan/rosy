常见问题

支持哪些浏览器？

目前支持桌面版Chrome和Edge,其他未测试和适配。

怎么手动安装？

在浏览器管理扩展中打开开发者模式,将下载的zip包拖入浏览器窗口即可。

房间上限是多少人？

理论上没有限制。

如果默认服务器抽风连不上怎么办？

可以在「设置 → 自定义服务器」里换一个服务器,同一房间内所有人需要填写同一个服务器地址。

支持哪些视频网站同步？

在线视频网站应该都能支持,如有问题可以反馈。

和远程控制的区别有哪些？

Rosy控制单位为浏览器当前tab页,只传输必要的指令操作,消耗极少流量。不过不使用时,希望大家能及时关闭房间,避免服务器资源浪费。

是否免费？

是,为爱发电。

自定义服务器

默认服务器可能不稳定，为了稳定使用和分散服务器压力，推荐使用EMQX Cloud Serverless或其他方式搭建自己专属的mqtt broker服务器。
